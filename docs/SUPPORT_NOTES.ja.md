# VoltFuel サポートノート(0.9.5)

このノートは、VoltFuel の仕組みと調整の考え方をまとめたものです。AI チャットに貼って相談する材料として使えます。English: [SUPPORT_NOTES.en.md](SUPPORT_NOTES.en.md)

## 1. VoltFuel とは
EdgeTX 用の、電圧だけで残量を推定するウィジェットです(電流センサー不要)。表示は `62%(48%)` の形です。
- `62%` = **sBAT**(VoltFuel の推定値)。起動時は静止電圧の換算値から始まり、その後は**下がる一方**です。
- `(48%)` = **rBAT**。BattAnalog 方式の「現在の電圧を表で換算した値」です。負荷がかかると低く出ます。

テレメトリセンサー: `sBAT`(常時)、`rBAT`・`rCEL`(セル電圧)・`rMIN`(使用中の MinCv、V 単位)は ExtraTelem がオンのときだけ出力されます。

## 2. オプション
| オプション | 既定値 | 役割 |
|---|---|---|
| Source | – | パック電圧のテレメトリ |
| BattType | LiPo | LiPo / LiPo-HV / Li-Ion / LiFePO4。セル数の自動判別と、`rBAT`・開始値の表にだけ使う。MinCv/MaxCv は変わらない |
| Cells | 0 | 0=自動判別(最初の 8 秒は判定し直し、その後固定) |
| ResPct | 35 | リザーブ。曲線上で 0% と表示する位置 |
| FallMv | 50 | サグフィルタ(mV/秒)。Source の電圧に対する制限 |
| MinCv | 286 | 「空」のセル電圧 ×100。主な調整項目 |
| MaxCv | 410 | 「満」のセル電圧 ×100 |
| ResetSw | – | 立ち上がりで、その時点の `rBAT` 相当の値に戻す |
| ExtraTelem | オフ | `rBAT`・`rCEL`・`rMIN` を出力 |

## 3. sBAT の計算(要点)
1. セル電圧 = Source ÷ セル数。
2. **サグフィルタ**: 下がる方向だけ、毎秒 `FallMv ÷ 1000 × 0.8` V までに制限(上がる方向は即時)。
3. **曲線**: `s = 3.00 + (v − MinCv) ÷ (MaxCv − MinCv) × 1.2`(3.00〜4.20 に制限)、`raw% = 100 ÷ (1 + exp(−6 × (s − 3.70)))`。v ≥ MaxCv で 100、v ≤ MinCv で 0。
4. **リザーブ**: `(raw − ResPct) × 100 ÷ (100 − ResPct)`(0〜100 に制限)。
5. **消費量**は増える方向だけ、最大 1%/秒で追従。`sBAT = 100 − 消費量`。

重要な性質: **最終 sBAT は、飛行中に最も下がったフィルタ後のセル電圧で決まります**。着陸後に電圧が戻っても、sBAT は戻りません。激しい飛行では低く、穏やかな飛行では高く出ます。

## 4. MinCv の調整
- 基準: 着陸後の**静止電圧**を BattAnalog の表で換算した値(`rBAT` または解析ツールの「静止換算%」)。実測の mAh ではありません。
- sBAT が換算より**高い** → MinCv を**上げる**。**低い** → **下げる**。
- 1 ステップ(0.01V)の効きは 0.3〜1 ポイントです。1 フライトのばらつきは ±3〜5 ポイントなので、**5〜10 ステップ単位**で動かし、**3 フライトほど**で判断します。
- ResPct も同じ向きに効きます(1 ステップあたりの効きは大きい)。ResPct を変えたら、MinCv を調整し直します。
- 例(作者のデータ。機体や較正で変わる): 4S と 6S の機体で MinCv はおよそ 270〜298(中心は 283 前後)。2S LiPo-HV の小型ヘリでは 258〜283(268 前後)。既定値 286 は、最初の表示が慎重な側に出るよう、あえて少し高めです。
- 深く放電した飛行(静止電圧が低い飛行)は、同じ MinCv でも、sBAT が換算より高く出る傾向があります。深く使う機体では、やや高めの MinCv が安全側です。

## 5. 解析ツール(VoltFuel_Tune.html、または送信機の Tune)の読み方
送信機の Tune 画面にも、同じ列(Conv、sBAT、Used、Match、Sens。`!` は、計算とログの差が 3 を超えた印)が出ます。使えないログ(短すぎる、飛行なし、末尾に静止区間なし)も、同じ条件でスキップされます。
| 列 | 意味 |
|---|---|
| 静止電圧/セル、静止換算% | ログ末尾 30 秒の平均電圧と、その換算値 |
| ログの最終 sBAT | ログの最後の sBAT |
| 使用 MinCv | ログの `rMIN`(×100) |
| 再現差 | 計算と実ログの最終 sBAT の差。±3 を超えたら、ResPct・FallMv・MaxCv が、ログ取得時と違う可能性 |
| 合わせる MinCv | 最終 sBAT が静止換算に一致する MinCv(シミュレーション) |
| 感度 | MinCv 1 ステップあたりの sBAT の変化(ポイント)。小さい(絶対値 0.15 未満)フライトは、集計から除外 |

機体ごとの「推奨 MinCv」は、その機体のフライトの誤差が最小になる値です。

## 6. 注意すべき点
- **電圧ソースの較正**が前提です。Offset や Ratio で補正してから、MinCv を調整します。較正が違うと、MinCv の値は他の機体や他のユーザーに当てはまりません。
- 電圧が 0.1V 刻みのセンサー(RxBt など)は、小さいパック(2S〜3S)で、換算が 5 ポイント以上跳ねます。
- Source を、セル電圧のセンサーにしたときは、Cells を 1 にします(FallMv は Source の電圧への制限なので、パック電圧のときとは効き方が変わります)。
- セル数の自動判別は、深く放電した 6S を 5S、LiPo 設定のままの LiPo-HV 6S を 7S と誤判別することがあります。
- 確認したのは、6S LiPo の数機種と、2S LiPo-HV の小型ヘリです。劣化したパック、低温、他の電池種は未検証です。
- 地上のログで、sBAT などのセンサーの値が、十数秒だけ 0 で記録された例が 1 回ありました。原因は分かっていません。念のため、飛行中は、ウィジェットの設定画面を開かないでください。
- ログの記録には、特殊機能(SF)の *SD Logs* が必要です。常に ON だと、送信機の電源を入れるたびにログが作られます。最低限、論理スイッチ `a>x`(V1 = 電圧の Source、V2 = 2V)で SF を動かし、機体の電源が入っている間だけ記録します。着陸後は、30〜60 秒、電源を入れたままにして、静止電圧を記録します。記録間隔は 1.0 秒です。

## 7. AI に相談するとき
次の材料を、このノートと一緒に貼ります。
1. 機体、電池(セル数、電池種、容量)、電圧の Source と較正の値
2. 設定(BattType、Cells、ResPct、FallMv、MinCv、MaxCv)
3. 解析ツールの表(テキストまたはスクリーンショット)
4. 困っていること(例: 「sBAT が高すぎる」)

AI の助言は誤ることがあります。MinCv の目安は、少数のフライトからの推定値です。着陸判断には、使わないでください。
