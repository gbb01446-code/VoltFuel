## 注意
- VoltFuel は**電圧だけからの推定値**です。実際の残量に対する精度は測っていません。**着陸判断の唯一の基準にしないでください**。
- 動作環境: **EdgeTX 2.12 以上**のカラー液晶タッチ機(白黒液晶機は非対応)と、**パック電圧のテレメトリ**(RxBt、Vbat、VFAS など)が必要です。電流センサーは要りません。ウィジェットのオプションを 10 個使います。

## 1. セットアップ
1. `VoltFuel_SD/` の中身を、SD カードの直下にコピーします(`/WIDGETS/voltfuel/` と `/SCRIPTS/TOOLS/` ができます)。
2. メインビューにウィジェットを追加し、設定を開きます。
3. **Source**(パック電圧のテレメトリ)を選びます。受信機自身の BEC 電圧ではなく、**パック電圧**を返すセンサーにしてください。
4. **BattType**(電池の種類)を合わせます。**Cells** は、0(自動)で構いません。深く放電したパックや LiPo-HV では、誤判別することがあるので、そのときは手動で指定してください。
5. **ExtraTelem をオン**にします。`rBAT`、`rCEL`、`rMIN` が出力され、解析に使えます。
6. テレメトリ画面で、`sBAT` などのセンサーが一覧に現れることを確認します(現れない場合は、「新しいセンサーを検出」を実行)。

## 2. 電圧ソースの較正(最初に必ず)
電圧のテレメトリは、較正されていないことが多く、数百分の 1 V ずれます。ずれたままだと、MinCv の調整が、その機体だけに合う値になります。

1. パックを**静止状態**(負荷なし)にして、信頼できる電圧計かバッテリーチェッカーで測ります。
2. 同じタイミングで、テレメトリ画面の Source の値を読みます。
3. 違うときは、*モデル設定 → テレメトリ* でセンサーを選び、**Offset**(一定の差)や **Ratio**(比例した誤差)を設定します。小数のオフセットは、Precision を 0.00 にすると入ります。
4. 電圧の違うパック(満充電と使用済みなど)で 2 点測ると、より確実です。

## 3. ログの設定
モデル設定の SD ログで、次のセンサーを記録します。
- 電圧の Source(RxBt、Vbat など)
- `sBAT`、`rBAT`、`rCEL`、`rMIN`
- あれば、電流、スロットル(解析で役立ちます)

**ログの記録スイッチ。** 特殊機能(SF)の *SD Logs* が有効になるまで、何も記録されません。まず、これを設定します。
- SF を常に ON にしておくと、送信機の電源を入れるたびに、飛行の有無にかかわらず、ログのファイルが作られ、SD カードに不要なログがたまります。
- 最低限、機体の電源が入っている間だけ ON になる論理スイッチで、SF を動かしてください。機能は `a>x`、V1 = 電圧の Source(たとえば RxBt)、V2 = 2V にします(0 より大きく、空のパックよりずっと低い値なら、いくつでも構いません)。
- こうすると、機体の電源が入っている間だけログが作られ、電源を切るまで続きます。着陸後の静止電圧も記録されるので、着陸後は 30〜60 秒、機体の電源を入れたままにしてください。
- 飛行せずに電源だけ入れたログは、作られます。Tune の画面は、それを自動でスキップし、**VoltFuel_Tools → Logs** で、まとめて削除できます(たとえば「N 秒より短いログ」)。
- *SD Logs* の記録間隔は、1.0 秒にしてください。

## 4. 調整用のフライト
1. 満充電のパックで、送信機の電源を入れ、機体の電源を入れます。約 9 秒後に、値が出ます(セル数を固定すれば約 2 秒)。
2. いつもどおり飛ばします。
3. **着陸後、機体の電源を入れたまま、30〜60 秒待ちます。**(静止電圧を記録するためです。)
4. 可能なら、**充電器で充電したときの mAh** を記録してください。実際の残量の、一番確かな基準になります。
5. パックを交換するときは、**送信機の電源を入れ直します**。送信機を入れたまま同じパックを戻すときは、電圧が安定してから ResetSw を操作します。

## 5. MinCv の調整
1. **送信機で:** SYS → Tools → VoltFuel_Tools → Tune で機体を選びます(先に *Settings* へ、ウィジェットと同じ設定を入れます)。または、PC で、3 フライトほどのログを `VoltFuel_Tune.html` に読み込みます。飛行していないログ(机上の通電、短すぎるログ、末尾に静止区間がないログ)は、自動でスキップされます。**VoltFuel_Tools → Logs** では、各ログのサイズと長さを見て、不要なログを削除できます。
2. 「ログの最終 sBAT」と「静止換算%」を見比べます。
   - sBAT が換算より**高い**(楽観的): MinCv を**上げる**。
   - sBAT が換算より**低い**(悲観的): MinCv を**下げる**。
3. 機体ごとの「推奨 MinCv」を参考に、設定します。
4. **5〜10 ステップ単位**で動かしてください。1 ステップは、sBAT を 0.3〜1 ポイントしか動かさず、1 フライトのばらつき(±3〜5 ポイント)に埋もれます。
5. 変えるのは、一度に 1 つのオプションだけにします。変更後も、3 フライトほどで判断してください。

参考: 作者の 4S と 6S の機体では、MinCv はおよそ 270〜298 でした(既定値 286。最初の表示が慎重になるよう、あえて少し高めです)。2S LiPo-HV の小型ヘリでは、258〜283(268 前後)でした。あくまで例で、機体や電圧の較正によって変わります。

## 6. 相談や報告のときに伝えてほしいこと
次の項目を、メモして、お知らせください。
- 機体(種類、サイズ)と電池(セル数、電池種、容量、C 数、使用回数や年数)
- 電圧の Source と、較正した値(Offset や Ratio)
- 設定(BattType、Cells、ResPct、FallMv、MinCv、MaxCv)
- ログの CSV、またはVoltFuel_Tune の表
- 着陸したときの sBAT と、充電した mAh(分かれば)
- 気づいたこと(表示、メッセージ、センサーが出ない、値の跳びなど)

## 困ったとき
- 「Select Source」や「Check Source」が出る → Source の設定を見直します。
- 値が出ない → 機体の電源が入っているか、センサーが選ばれているかを確認します。
- 詳しくは、`VoltFuel_SD/WIDGETS/voltfuel/README.ja.md` と `docs/SUPPORT_NOTES.ja.md` をご覧ください。
