# VoltFuel(ボルトフューエル)

**電圧だけで残量を推定する EdgeTX 用ウィジェット**(電流センサー不要)

English: [README.md](README.md)

VoltFuel は、LiPo の**パック電圧テレメトリだけ**から残量を推定し、バーと 2 つの数字で表示します。例: **`62%(48%)`**

| 表示 | 意味 |
|---|---|
| `62%` | **VoltFuel の推定値**。起動時は静止電圧の換算値から始まり、その後は**下がる一方**です。サグフィルタと下降レート制限で、スロットル操作による急な上下動を抑えます。テレメトリセンサー **`sBAT`** としても出力されます。 |
| `(48%)` | **BattAnalog 方式の値**。EdgeTX 標準の BattAnalog ウィジェットと同じ「セル電圧 → %」の表を、**現在の電圧**にそのまま当てはめた値です。独立した参考値で、着陸後に電圧が落ち着いてから見るのが最も役に立ちます。 |

> **Rotorflight とは無関係です。** Rotorflight の「SmartFuel」は別の機能です。VoltFuel は、パック電圧を出すテレメトリなら何でも使えます。

## 動作環境

- EdgeTX **2.12 以上**のカラー液晶タッチ機(TX16S、TX15、GX15 で開発)。白黒液晶機は非対応です。VoltFuel はウィジェットオプションを 10 個使います。
- **パック電圧**を返すテレメトリセンサー(VFAS、RxBt、Vbat など)。受信機自身の BEC 電圧しか返さない受信機では使えません。

## インストール

1. **`voltfuel`** フォルダを SD カードの `/WIDGETS/` にコピーします(`/WIDGETS/voltfuel/main.lua` になります)。フォルダ名は 8 文字以内が条件です。
2. 送信機で、メインビューを長押し → ウィジェットを追加 → **VoltFuel** を選びます。
3. ウィジェットを長押し → **Settings** で **Source** を選びます。
4. ウィジェットに値が表示されると、テレメトリのセンサー一覧に **`sBAT`** が現れます。(現れない場合は、テレメトリ画面で「新しいセンサーを検出」を実行してください。)

`sBAT` を出力する別のウィジェットと同時には使わないでください。

## 使う前に: 電圧ソースの確認

VoltFuel の精度は、入力する電圧の精度を超えられません。テレメトリの電圧(RxBt など)は、たいてい較正されておらず、数百分の 1 V ほど高く、または低く出ることがあります。また、0.1V 刻みでしか出さないセンサーも多くあります。小さいパックでは、この影響が大きくなります。1 セルあたり 0.01V の違いで、中間域の換算値が約 2 ポイント動きます。2S のパックでは、0.05V の誤差が、1 セルあたり 0.025V にあたります。

1. パックを**静止状態**(負荷なし)にして、信頼できる電圧計かバッテリーチェッカーで、電圧を測ります。
2. 同じタイミングで、送信機のテレメトリ画面で、Source のセンサーの値を読みます。
3. 値が違うときは、*モデル設定 → テレメトリ* でセンサーを選び、*編集*で **Offset**(一定の差: 実測 − 表示)や **Ratio**(比例した誤差: 実測 ÷ 表示)を設定して、センサーを補正します。Offset に小数を入れたいときは、センサーの **Precision** を 0.00 にしてください。
4. より正確にするには、電圧の違うパック(たとえば満充電と使用済み)でも測り、2 点を使います。
5. これを、MinCv の調整の**前に**行ってください。調整した MinCv は、そのときの較正でだけ有効です。あとから Offset や Ratio を変えたら、MinCv を調整し直してください。

基準にする電圧計にも許容誤差があります。信頼できるものを使ってください。

## オプション

| オプション | 既定値 | 意味 |
|---|---|---|
| Source | – | パック電圧のテレメトリセンサー |
| BattType | LiPo | LiPo / LiPo-HV / Li-Ion / LiFePO4。**セル数の自動判別と、括弧内の BattAnalog 方式の値にだけ**使われます。MinCv / MaxCv は**変わりません**。 |
| Cells | 0 | セル数。`0` で自動判別(BattAnalog の方式。最初の 8 秒間は判定し直し、その後固定)。 |
| ResPct | 35 | リザーブ。曲線上で 0% と表示する位置です。大きいほど低く表示され、0% に早く着きます。変えたら MinCv の再調整が必要です。 |
| FallMv | 50 | サグフィルタ。フィルタ後の電圧が下がってよい速さ(mV/秒)。小さいほど滑らかです。 |
| MinCv | 286 | 「空」のセル電圧 ×100(曲線の 0%)。**主な調整項目**です。大きいほど低く表示されます。 |
| MaxCv | 410 | 「満」のセル電圧 ×100(曲線の 100%)。他の電池種向けには調整していません(LiPo-HV は 2S の 1 フライトのみ確認)。 |
| TxtColor | 白 | 文字色 |
| ResetSw | – | 任意のスイッチ。オフ→オンの瞬間に、その時点の BattAnalog 方式の値へ戻します。 |
| ExtraTelem | オフ | 後で分析するために、テレメトリセンサー `rBAT`、`rCEL`、`rMIN` も出力します(下記)。 |

## テレメトリセンサー

| センサー | 出力 | 意味 |
|---|---|---|
| `sBAT` | 常時 | VoltFuel の推定値(%) |
| `rBAT` | ExtraTelem オン | BattAnalog 方式の値(%)。**現在の電圧**を、単純に電圧 → % に換算した値です。負荷がかかると低く出て、静止時に実残量に最も近くなります。 |
| `rCEL` | ExtraTelem オン | セル電圧(V) |
| `rMIN` | ExtraTelem オン | 使用中の MinCv(V 単位。260 なら 2.60)。フライトごとの調整値が SD ログに残ります。 |

`rBAT`、`rCEL`、`rMIN` は、セル数が確定してから出力されます(セル数が自動判別なら、テレメトリが現れてから約 8 秒後)。センサーは、最初の値が出たあとにテレメトリのセンサー一覧に現れます。センサー名は、作られたときに固定されます。あとでフライトを分析するには、これらを SD ログに記録してください。

## 電源投入・パック交換・リセット

- 開始値は **100% ではありません**。テレメトリが現れてから、セル数が自動判別なら約 8〜9 秒(セル数を固定していれば約 2 秒)で、セル数の判別と電圧の安定待ちが終わり、静止電圧の換算値(BattAnalog 方式)から始まります。使用済みパックなら実際の残量から、満充電(4.19V/セル)なら約 99% から始まります。
- **自動リセットはありません。** 着陸しても、テレメトリが途切れても、値は保持されます。
- **パックを交換するとき**は、送信機の電源を入れ直してください。
- **同じパックを戻すとき**(送信機は入れたまま)は、電圧が安定するのを待って **ResetSw** を操作します(機体を静止させ、電圧が落ち着いてから)。

## 表示

- 残量は**セグメント式のバーグラフ**(20 セグメント)で表示します。20% までが赤、50% までがオレンジ、それより上が緑です。点灯したセグメントは塗りつぶし、消灯したセグメントは枠だけで表示します。
- 枠が大きいときは、バーの上の行に、パック電圧、セル数、セル電圧を表示します(例: `25.15V 6S (4.19V/c)`)。小さい枠では、パーセントだけを表示します。
- **最初の値が出る前**(たとえば機体の電源がまだ入っていないとき)は、通常のレイアウトを数値 0 で表示します。机の上でレイアウトを確認できます。

| 状態表示(大きい枠、最初の値が出る前) | 意味 |
|---|---|
| Select Source | ウィジェット設定で Source が未選択です。 |
| Check Source | Source の値が、パック電圧として不自然です。 |
| Acquiring... | テレメトリはあり、セル判別と電圧安定を待っています。 |

値が表示されたあとでテレメトリが途切れた場合は、最後の値を保持し、「No telemetry (value held)」と表示します。状態表示の行を出せない低い枠では、レイアウトの代わりにメッセージの文字を表示します。

## MinCv の調整

まず、電圧ソースを較正してください(上記)。

既定値(286)は、作者の 4S と 6S の機体(飛行機 1 機種とヘリ 3 機種、電圧は RxBt または Vbat)のログから決めました。最終的に落ち着いた電圧の静止電圧換算値(実際に測った充電量(mAh)では**ありません**)に、最終値を合わせる MinCv は、**およそ 270〜298**(中心は 283 前後)でした。最初の表示が慎重(低め)な側に出るよう、あえて少し高めにしています。小さくて負荷の高いパック(たとえば 2S 400mAh のヘリ)では、ずっと低い値(268 前後)が必要で、既定値では低く表示されます。機体ごとに数フライトかけて合わせてください。

1. いつもどおり飛ばして着陸します。機体の電源は入れたままにします。
2. 電圧が落ち着くまで待ちます(30〜60 秒)。
3. 大きい数字(VoltFuel)と、括弧内の値を見比べます。
4. VoltFuel のほうが**高い**なら MinCv を**上げ**、**低い**なら**下げ**ます。着陸付近では、MinCv を 1 ステップ(0.01V)変えると、結果が約 0.7〜1 ポイント動きます。5 ポイントの差なら、5〜7 ステップが目安です。
5. 2〜3 フライト繰り返します。変えるオプションは**一度に 1 つ**にしてください。

補足: 括弧内の値は静止電圧の単純な換算なので、着陸後に電圧が戻ってからでないと、公平な基準になりません。RxBt のように 0.1V 刻みのセンサーでは、精度は数 % 程度に制限されます。

## 読み上げの例

`sBAT < 60` のロジカルスイッチを作り、そのスイッチで特殊機能「値を再生」(`sBAT`、数秒ごとに繰り返し)を設定します。しきい値は、ご自分の着陸の方針に合わせてください。

## 制限事項(必ずお読みください)

- **電圧だけからの推定値**です。実際の残量に対する精度は**測っていません**。確認したのは、約 4.2V/セルまで充電した 6S パック(と 2S LiPo-HV の 1 フライト)だけで、劣化したパック、低温のパック、他の電池種は未検証です。
- セッション中、値は**上がりません**(ResetSw を使ったときを除く)。
- セル数の自動判別は、深く放電したパックを 1 セル少なく、BattType が LiPo のまま LiPo-HV を 1 セル多く誤判別することがあります。その場合は **Cells** を手動で指定してください。
- **着陸判断を、これ 1 つだけに頼らないでください。**

## 出典とライセンス

- 電圧だけの推定方式(シグモイド曲線、リザーブの再スケール、サグ制限フィルタ、レート制限つきの消費量、安定判定)は、Rotorflight Lua スイート(EdgeTX 用)の SmartFuel の電圧モードの考え方に沿っています。VoltFuel は、コピーではなく独立した再実装です。
- **BattAnalog**(EdgeTX、Copyright Offer Shmuely、GPLv2): セル電圧 → % の表、電池の種類、セル数判別の規則。
